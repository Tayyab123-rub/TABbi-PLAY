# TABbi PLAY - Web Music Player

TABbi PLAY is an interactive music streaming web dashboard featuring custom audio controls, speed toggles, dark/light themes, and animated equalizer visuals.

## 🎵 API & Copyright Disclaimer
- This project utilizes the **Public iTunes Search API** (`https://itunes.apple.com/search`) for track previews, metadata, and album art.
- All audio samples played in this application are short **30-second promotional previews** streamed directly from Apple's official servers.
- **No media files are hosted or stored on this repository or project server.**
- All rights, trademarks, and media content belong strictly to their respective owners and record labels.
